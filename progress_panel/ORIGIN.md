# Source provenance

The product progress panel adapts the user-selected RelayForge Development
0.1.20 source from the sibling RelayForge project maintained under the same
`mingjw6505` GitHub account. The user requested this adaptation in the local
RelayForge Product workspace. No additional license grant is asserted here.

Reused foundations: MCP stdio framing/resource dispatch, private SQLite cache,
bounded revisions/history, Skill file-loading receipts, the poller, card CSS,
MCP Apps initialization, and UI build/preview tooling. Product source collection,
approval validation, tool schemas, view mapping and product content are adapted
for this plugin. The development-plan document records reference file digests.

Bundled third-party JavaScript license texts are generated by `web/build.mjs`
into `THIRD_PARTY_NOTICES.txt`; dependencies are pinned in `web/package-lock.json`.
